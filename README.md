# 스위트 홈

<스위트 홈>은 학교 프로젝트를 통해 제작된 비주얼 노벨 게임입니다.

## 팀원 소개

- 🎨 **페인터**(AprilsPainter): 프로그래밍, 기획 담당
- 🍅 **토마토**(LuckyTomato7): 디자인, 기획 담당

## 실행

1. 업로드 되어 있는 zip 파일을 다운로드 받습니다.
2. 다운로드 받은 파일의 압축을 풉니다.
3. 폴더 안에 있는 Sweet_Home.exe 파일을 실행시킵니다.
